PAC

A desktop voice assistant for Windows with augmented reality: show it an object, teach it a name, and it recognises it again.

Install

  1. Download and unzip.
  2. Run PAC.exe. If Windows SmartScreen warns, choose More info, then Run anyway (the app is not code-signed yet).
  3. Allow camera and microphone access.
  4. Open Menu > Augmented reality to start.

Needs Windows 10 or 11, a webcam and a microphone. PAC updates itself: it checks this site for new versions.

Privacy

Everything stays on your laptop. PAC keeps only numbers describing objects you teach it, never pictures. This site does not track you.
